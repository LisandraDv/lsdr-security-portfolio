Lisandra's Professional Profile

About Me

I’m a Cloud & Cybersecurity Engineer with 3+ years of hands-on experience working across cloud infrastructure, identity, endpoint security, Microsoft security and hybrid environments.

My day-to-day work spans Azure and Microsoft 365 administration, Entra ID and IAM, Conditional Access, PIM, Intune, Defender, Sentinel, security hardening, governance, monitoring and infrastructure operations. I also work with hybrid and private cloud technologies including VMware, Nutanix, Citrix and Windows Server.

I enjoy turning security requirements into practical solutions — from Zero Trust controls, endpoint security baselines and identity governance to cloud posture improvements, automation, documentation and resilient infrastructure.

Beyond daily operations, I build hands-on projects around Cloud Security, DevSecOps, Infrastructure Security, Application Security and AI-assisted security tooling. One of my projects is AI-Powered Security Email Triage, a local AI solution for cybersecurity email triage, classification and prioritization. I continuously expand my skills through certifications, cybersecurity programs, international training, technical communities and labs.
